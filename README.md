# Justube Focus Kit

**حوّل YouTube الحقيقي — التطبيق الرسمي والموقع الرسمي — إلى تجربة تركيز للدراسة ومتابعة الأخبار، بدون تطبيق جديد وبدون واجهة بديلة.**

مستودع الإعدادات والفلاتر والأدلة هذا (اسم المستودع على GitHub ما زال `pro-fashino-skins` — يمكن إعادة تسميته لاحقًا) هو تنفيذ قرار مالك المشروع: *تعديل تجربة YouTube الأصلية نفسها قدر الإمكان، لا استبدالها*.

---

## الفكرة في سطر

طبقات تعمل **فوق YouTube الأصلي** (حسابك، واجهتك، اشتراكاتك، سجلك — كلها كما هي) وتزيل عناصر التشتيت:

| الطبقة | أين تعمل | ماذا تزيل |
|---|---|---|
| **1. إعدادات YouTube الرسمية (2026)** | تطبيق Android/iOS | فيد Shorts (حد 0 دقيقة)، معاينات متحركة، autoplay، توصيات Shorts |
| **2. ReVanced / RVX** | تطبيق YouTube الرسمي على Android (نسخة مرقعة على جهازك) | Shorts من **كل** الأسطح بما فيها التبويب والبحث، autoplay، فلترة كلمات وقنوات |
| **3. فلاتر uBlock Origin + BlockTube (+ سكريبت اختياري)** | youtube.com الحقيقي في المتصفح (حاسوب + Firefox/Kiwi على Android) | أرفف/تبويب/نتائج Shorts، Playables، تحويل روابط Shorts لفيديو عادي، حظر كلمات/قنوات/مدة ≤60s |

كل طبقة مستقلة وقابلة للتراجع، والطبقات تتراكم. التفاصيل والصدق الكامل عن الحدود في [`docs/SOURCES.md`](docs/SOURCES.md).

## البدء السريع (Android — الجهاز الأساسي للمالك)

1. **5 دقائق، قانوني 100%:** طبّق [`docs/ar/01-official-settings.md`](docs/ar/01-official-settings.md) — حد Shorts = 0، Show fewer Shorts، autoplay off، Playback in feeds off.
2. **لإزالة Shorts جذريًا من التطبيق الرسمي:** اتبع [`docs/ar/02-revanced-android.md`](docs/ar/02-revanced-android.md) — الترقيع يتم على جهازك (لا يمكن بناؤه من بيئة التطوير)، والدليل يحدد الرقع الموصى بها للتركيز الدراسي حرفيًا.
3. **لتصفح الحاسوب/متصفح الهاتف:** [`docs/ar/03-browser-filters.md`](docs/ar/03-browser-filters.md) — استورد [`filters/justube-focus.txt`](filters/justube-focus.txt) في uBlock Origin وفعّل إعداد [`presets/blocktube-recommended.md`](presets/blocktube-recommended.md).

ثم نفّذ **قائمة اختبار القبول**: [`docs/ar/04-testing-checklist.md`](docs/ar/04-testing-checklist.md) (~15 دقيقة، 31 بندًا).
وعند أي عطل: [`docs/ar/05-troubleshooting.md`](docs/ar/05-troubleshooting.md).
ولتحويل YouTube نفسه إلى مكتبة دراستك ومصدرك الإخباري (قوائم لكل مادة، الاشتراكات كرئيسية، الاستكمال، المراجعة): [`docs/ar/06-study-workflow.md`](docs/ar/06-study-workflow.md).

## الفحص الآلي

```bash
npm run check   # = validate-filters + node --check للسكريبت — بلا أي تبعيات (dependencies: {})
```

الحالة الحالية: ✔ 52 قاعدة نشطة، 0 أخطاء صياغة، سكريبت سليم.
**ما لم يُختبر (بصراحة):** السلوك البصري داخل متصفح حقيقي على youtube.com — بيئة التطوير sandbox بلا متصفح وبلا وصول للموقع؛ لذلك قائمة الاختبار اليدوية (31 بندًا) جزء رسمي من التسليم وليست ترفًا.

## مبادئ غير قابلة للتفاوض في هذا المشروع

1. **لا تطبيق جديد ولا واجهة تحاكي YouTube** — كل شيء يعمل فوق YouTube الحقيقي.
2. **لا منع للوصول إلى المعرفة** — الروابط المباشرة للـShorts تُحوَّل إلى فيديو عادي بدل منعها، والبحث يبقى كاملًا، والفلاتر تُطبَّق على التوصيات لا على الوصول.
3. **لا جمع بيانات ولا اتصالات خارجية** — السكريبت والفلاتر محلية 100%.
4. **لا أكواد مجهولة** — كل قاعدة/رقعة/دالة لها مصدر موثق بترخيصه وحالته.
5. **الصدق عن الحدود** — ما لا نستطيع تنفيذه أو اختباره من هنا مذكور صراحة في مكانه.
