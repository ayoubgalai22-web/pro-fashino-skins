# 4) قائمة اختبار القبول — نفّذها على أجهزتك الحقيقية

> **ما اختُبر آليًا داخل بيئة التطوير (2026-10-09):**
> - ✔ صياغة قائمة الفلاتر: `node scripts/validate-filters.mjs` → 52 قاعدة نشطة + 10 اختيارية، صفر أخطاء صياغة.
> - ✔ صياغة السكريبت: `node --check userscripts/justube-focus.user.js` → سليم.
> - ✔ التحقق من مصادر القواعد: القوائم الأصلية MIT حية ومحدّثة (أبريل/يونيو 2026)، وتوافق أسماء رقع RVX v4.3.0 من ملف patches-list.json الرسمي.
>
> **ما لا يمكن اختباره من بيئة التطوير (بصراحة):** بيئة التطوير sandbox بلا
> متصفح حقيقي وبلا وصول إلى youtube.com، لذا كل اختبار بصري/سلوكي أدناه يجب أن
> تنفذه أنت مرة واحدة بعد التثبيت (≈15 دقيقة). أي بند يفشل → دليل 5.

## أ) الحاسوب — Firefox + uBlock Origin (+ BlockTube + السكريبت اختياريًا)

| # | الاختبار | الخطوات | المتوقع |
|---|---|---|---|
| A1 | الرئيسية بلا Shorts | افتح youtube.com (مسجّل الدخول) ومرر الرئيسية كاملة | لا رفّ Shorts ولا بطاقات Shorts ولا قسم Playables |
| A2 | الشريط الجانبي | انظر الشريط الجانبي (العريض والمصغر) | لا رابط Shorts |
| A3 | البحث | ابحث عن موضوع دراستك (مثلًا "bac maths limite") | لا نتائج /shorts/ ولا رفوف Shorts بين النتائج |
| A4 | رقائق البحث | شريط الفلاتر أعلى النتائج | لا رقاقة "Shorts" |
| A5 | الاشتراكات | افتح /feed/subscriptions | لا صفوف Shorts (فيديوهات قنواتك الطويلة سليمة) |
| A6 | صفحة قناة | افتح قناة فيها shorts كثيرة | لا تبويب Shorts |
| A7 | تحويل رابط Short | الصق في شريط العنوان رابط `youtube.com/shorts/<أي id>` | يُفتح كفيديو عادي `/watch?v=` (أو يُحجب — كلاهما مقبول حسب إعدادك) |
| A8 | التشغيل التلقائي | افتح أي فيديو طويل | مفتاح Autoplay مطفأ (السكريبت يطفئه إن كان مضاءً) وبعد انتهاء الفيديو لا يبدأ فيديو آخر |
| A9 | الاقتراحات الجانبية | صفحة المشاهدة | لا فيديوهات بوسم SHORTS في العمود الجانبي |
| A10 | BlockTube — المدة | فعّل Advanced blocking (§4 من preset) | الفيديوهات ≤ 60s تختفي من الرئيسية |
| A11 | BlockTube — الكلمات | أضف كلمة اختبار ثم ابحث/تصفح | كل فيديو عنوانه يحويها يختفي من الفيد |
| A12 | الثبات | أغلق المتصفح كاملًا وافتحه مجددًا | كل ما سبق ما يزال نافذًا (الفلاتر والإعدادات محفوظة محليًا) |
| A13 | عدم الكسر | صفحة السجل /feed/history | تعمل طبيعيًا (القوائم تستثنيها عمدًا) |
| A14 | الأداء | صفحتان رئيسيتان + بحث + فيديو | لا تجمّد/بطء ملحوظ مقابل بدون فلاتر |
| A15 | الاختياري Focus | فعّل أسطر إخفاء التعليقات/الاقتراحات | تُخفى عند الطلب وتعود بتعطيل السطر |

## ب) هاتف Android — Firefox for Android + uBlock Origin

| # | الاختبار | المتوقع |
|---|---|---|
| B1 | الرئيسية (m.youtube.com) | لا رفوف Shorts |
| B2 | الشريط السفلي | لا زر Shorts (pivot-shorts) |
| B3 | البحث | لا نتائج بوسم SHORTS ولا أرفف shorts |
| B4 | صفحة قناة | لا تبويب Shorts |
| B5 | الاشتراكات | لا بطاقات shorts |
| B6 | الثبات بعد إغلاق Firefox | ما يزال نافذًا |

## ج) هاتف Android — تطبيق ReVanced/RVX (بعد البناء)

| # | الاختبار | المتوقع |
|---|---|---|
| C1 | فتح التطبيق | لا يستأنف مشغل Shorts عند الإقلاع |
| C2 | الشريط السفلي | لا تبويب Shorts |
| C3 | الرئيسية | لا أرفف Shorts؛ والكلمات المحظورة في Hide layout components لا تظهر |
| C4 | البحث | لا نتائج Shorts |
| C5 | تشغيل فيديو → إنهائه | لا انتقال تلقائي (Disable playlist autoplay + Autoplay مطفأ) |
| C6 | الاشتراكات/السجل/Watch Later | تعمل كلها بحسابك الحقيقي كالمعتاد |
| C7 | إعادة التشغيل بعد يوم | كل الإعدادات محفوظة |
